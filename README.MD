# 1DMC



Decompilation + web port of this: https://delugedrop.itch.io/linecraft.

Currently, fullscreen doesn't work in the web runtime, I might fix that.
I have successfully built it with GameMaker 2022.5, I don't guarantee it will work in any other version of GameMaker.

All the code + assets in this repo belong to DelugeDrop, I just decompiled the game.

I recommend zooming in to 500% on the web port to be able to play.
